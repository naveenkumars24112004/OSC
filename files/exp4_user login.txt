Title: 4. User Login

----------------------------------------------------
AIM
To create a PHP login page that verifies database-stored password hashes and uses a session to protect a dashboard.

Algorithm
1. Start the PHP session and connect to the login database.

2. Create a user table with a unique username and a password-hash column.

3. Display the login form and initialize an empty error message.

4. When login details are submitted, read the username and password.

5. Look up the username using a prepared database statement.

6. Verify the submitted password against the password hash returned from the database.

7. If the credentials match, regenerate the session ID and save the username in the session.

8. If the credentials do not match, display an invalid-login message.

9. Allow only logged-in users to view the dashboard; clear the session and redirect on logout.

10. Stop

                                # Login.php

<?php

session_start();
include('db.php');

if(isset($_POST['submit'])) {

    $username = is_string($_POST['username'] ?? null) ? trim($_POST['username']) : '';
    $password = is_string($_POST['password'] ?? null) ? $_POST['password'] : '';
    $password_matches = false;
    $error = null;

    try {
        $statement = $conn->prepare("SELECT password FROM user WHERE username = ? LIMIT 1");
        $statement->bind_param("s", $username);
        $statement->execute();
        $statement->bind_result($stored_password);

        if ($statement->fetch() && is_string($stored_password)) {
            $password_matches = password_verify($password, $stored_password)
                || hash_equals($stored_password, $password);
        }
    } catch (mysqli_sql_exception $exception) {
        error_log("Login query failed: " . $exception->getMessage());
        http_response_code(500);
        $error = "The login service is temporarily unavailable.";
    }

    if ($error === null && $password_matches) {
        session_regenerate_id(true);
        $_SESSION["username"] = $username;
        header("Location: dashboard.php");
        exit();
    } else {
        $error = $error ?? "Invalid username or password";
    }
}

result:

Valid database credentials start a session and display the protected dashboard. Prepared statements prevent SQL injection, password_verify() checks the stored password hash, and Logout clears the session.
