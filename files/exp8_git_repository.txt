Title: 8. Git Repository

----------------------------------------------------
AIM
To create a local Git repository, track project files, save a commit, and inspect the repository status and history.

Algorithm
1. Open a terminal in the project folder.

2. Initialize a new local Git repository.

3. Check whether Git requires a user name and email, and configure them if necessary.

4. Add the project files to the staging area.

5. Create a commit with a descriptive message.

6. Rename the current branch to main.

7. Add the GitHub repository URL as the origin remote.

8. Push the main branch to the remote repository.

9. Check the working-tree status and view the commit history.

10. Stop

---------------------------------------------------
program:
Git Commands

git init

git add .

git commit -m "Initial commit"

git branch -M main

git remote add origin <GitHub-URL>

git push -u origin main
---------------------------------------------------
result:

A local Git repository is created, the project files are committed, and the selected branch is pushed to the configured GitHub remote. Replace <GitHub-URL> and the author details with your own values before running the commands.
