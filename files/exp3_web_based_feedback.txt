Title: 3. Web-Based Feedback Form

----------------------------------------------------
AIM
To create a PHP and MySQL feedback application that accepts a user's name, email address, and feedback message, stores the information, and displays saved feedback.

Algorithm
1. Start

2. Connect to the MySQL feedback database and set the connection character set.

3. Create a table to store feedback IDs, names, email addresses, messages, and submission times.

4. Display a form with fields for the user's name, email address, and feedback.

5. When the form is submitted, trim and validate the name, email address, and message.

6. If validation fails, display an error and retain the entered values.

7. If validation succeeds, prepare an INSERT statement and bind the submitted values.

8. Execute the statement and display a success message or a database error.

9. On the feedback list page, retrieve saved records and safely display each field.

10. Stop

  $statement = mysqli_prepare($conn, "INSERT INTO feedback(name, email, message) VALUES(?, ?, ?)");

  if(mysqli_stmt_execute($statement)){

result:

HOW TO RUN THIS program

                                    # IN PHP MY ADMIN
CREATE DATABASE IF NOT EXISTS feedbackdb;
USE feedbackdb;

CREATE TABLE IF NOT EXISTS feedback (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  email VARCHAR(255) NOT NULL,
  message TEXT NOT NULL
);
