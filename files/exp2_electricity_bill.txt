Title: 2. Electricity Bill

----------------------------------------------------
AIM
To develop a PHP script that calculates an electricity bill using the first 100 units at ₹2.50 per unit, additional units at ₹3.50 per unit, and a fixed charge of ₹50.

Algorithm
1. Start

2. Initialize the consumer name, units, charges, and error message.

3. Display a form that accepts the consumer name and units consumed.

4. When the form is submitted, read the name and units from the POST request.

5. Check that the name is present and the units are numeric and non-negative.

6. If the input is invalid, set and display a validation error.

7. If units are 100 or less, calculate the energy charge at ₹2.50 per unit.

8. If units exceed 100, charge the first 100 at ₹2.50 and the remainder at ₹3.50 per unit.

9. Add the ₹50 fixed charge and display the consumer details and formatted bill total.

10. Stop

---------------------------------------------------

if ($_SERVER["REQUEST_METHOD"] == "POST") {
  $name = htmlspecialchars($_POST['consumer_name']);

    // Calculation Logic

    // Remaining units @ ₹ 3.50
   if ($units <= 100) {

}
