Title: 1. Image Slide Show

----------------------------------------------------
AIM
To design an automated image slideshow web application using JavaScript DOM manipulation methods and the setInterval() function to cycle through an array of images at defined time intervals.

Algorithm
1. Start

2. Create an HTML page and add an image element with a unique ID.

3. Add a CSS file and style the image size, alignment, and cropping.

4. Create a JavaScript file and link it to the HTML page.

5. Declare an array containing the paths of the slideshow images.

6. Set the current image index to 0 and find the image element using its ID.

7. Define a function to advance the index to the next image.

8. Use the remainder operator to reset the index to 0 after the final image.

9. Update the image element's src and use setInterval() to call the function every 3 seconds.

10. Stop

---------------------------------------------------
program:
                                    # Index.html

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Image Slideshow</title>
  <link rel="stylesheet" href="./style.css" />
</head>
<body>
 <img src=".//assets/image1.jpg" alt="no image"  id ="slide_show"  class="image"/>
<script src="./app.js"></script>
</body>
</html>

                                    # style.CSS
.image{
  height:500px;
  width:500px;
  margin:auto;
   display: flex;
   justify-content:center;
}

                                    # App.js
let images=[
   "./assets/image1.jpg",
   "./assets/image2.jpg",
   "./assets/image3.jpg",
];


let index=0;
let slide = document.getElementById('slide_show');
let changeimg=()=>{
  index++;//index=index+1
   if(index >=images.length){
    index=0;
  }
   slide.src =images[index];
}
setInterval(changeimg,2000);
---------------------------------------------------
result:

The web page displays an image and advances to the next image every 3 seconds, looping continuously without a page reload.
